# CITY EATER

Одиночная HTML5-аркада: управляй чёрной дырой, поглощай настоящие здания и вырастай. Два вручную выбранных участка OpenStreetMap: **Пушкин** и **Гатчина**, по **10 000 × 10 000 м** каждый. Цель — **80% суммарной площади зданий**, без ограничения времени.

**Стек:** JavaScript ES modules, Vite, MapLibre GL JS, self-hosted PMTiles, отдельные чанки геометрии, IndexedDB. Нет Mapbox, коммерческих ключей, внешнего игрового backend или запросов к публичным OSM tile servers во время игры. Шрифты поставляются с приложением.

## Запуск

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Node.js 22+ рекомендован. Vite выводит `dist/`; относительный `base: './'` подходит для GitHub Pages в подпапке репозитория. Публикация: содержимое `dist/` в `docs/`, файл `docs/.nojekyll`, Pages → branch `main`, directory `/docs`.

HTTP-сервер должен поддерживать **Range-запросы** для PMTiles и выдавать `206 Partial Content`. Кросс-доменные карты дополнительно требуют корректного CORS. `file://` не поддерживается.

## Управление

- ПК: WASD / стрелки. Escape — пауза.
- Телефон или мышь: нажми на свободную область карты и тяни плавающий джойстик.
- Светлые здания подходят по радиусу; поглощение начинается автоматически, когда весь контур помещается в отверстие.
- Крупные здания препятствуют движению; при касании дыра скользит вдоль контура.
- Прогресс сохраняется автоматически в текущем браузере. Очистка данных сайта удалит прохождения и рекорды.

## Архитектура

- `src/geometry.js`: локальные метрические координаты, минимальный охватывающий круг, Polygon/MultiPolygon с отверстиями, непрерывные столкновения и скольжение, пространственная сетка.
- `src/repository.js`: потоковая подгрузка/выгрузка чанков 1×1 км и индекс активных зданий; уничтоженные ID живут отдельно. Игрок не заходит в ещё не загруженную зону столкновений.
- `src/renderer.js`: собственный MapLibre-стиль PMTiles, управляемый GeoJSON-слой зданий, canvas-дыра и ограниченные анимации поглощения.
- `src/state.js`: однократная награда, прогресс по площади, радиус `sqrt(18² + 0.06 × mass)`, результаты и рекорды.
- `src/storage.js`: IndexedDB-прохождения, рекорды и разблокировки; localStorage только для небольших настроек. Версия OSM-набора проверяется перед восстановлением.
- `src/input.js`: клавиатура, pointer capture, плавающий джойстик, pointer cancellation.
- `src/main.js`: жизненный цикл, интерфейс, pause/resume, победа/следующий уровень, сохранения.

Камера следует за дырой и отдаляется с ростом. На старте загружаются 4 чанка, а не вся геометрия 100 км². При цели 80% радиус составляет приблизительно 480 м в Пушкине и 425 м в Гатчине; активная область остаётся локальной.

## Данные и лицензии

Игровая база содержит **25 202 реальных здания**: 12 721 в Пушкине, 12 481 в Гатчине. Каждое целиком внутри локального квадратного участка. Идентификаторы `w<OSM way ID>` / `r<OSM relation ID>` стабильны внутри версии набора. Дубликаты и составные объекты нормализованы, внутренние дворы сохранены.

Данные © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Производная база, исходные разрешённые выгрузки, запросы, timestamps и SHA-256 опубликованы в [`public/data`](public/data/README.md). Сырые исходники доступны для лицензии и воспроизводимости, но игра их не загружает. Пайплайн и проверка доставки находятся в `scripts/`.

## Проверка

`npm test` проверяет 30 сценариев: геометрию и непрерывные столкновения, реальные границы и ID всех зданий, площадь прогресса, однократную награду, смену версии, IndexedDB, чанки/повторную загрузку/ошибки и ограниченный размер активной сцены к концу уровня.

В URL `?test=1` включается диагностическая панель. Она позволяет переместиться к настоящему подходящему зданию, выгрузить и вернуть чанки, сохранить контрольную точку и ускоренно достичь цели на настоящих OSM-ID. Панель изменяет прогресс **только текущего браузера**; по обычному адресу она отсутствует. FPS диагностируется по реальному uncapped времени кадров; физический timestep ограничен отдельно.

### Известные ограничения прототипа

- Реальные iPhone/Safari и Android/Chrome ещё требуют отдельного тестирования FPS, памяти и длительных сессий. Размер окна настольного браузера не заменяет реальные мобильные устройства.
- Геометрия использует локальную equirectangular-проекцию. Это точный квадрат в выбранной локальной системе, не геодезическая съёмка.
- Баланс роста и длительность прохождения требуют пользовательских тестов. Автоподбор районов и автоматическая оценка сложности не реализованы согласно GDD.
- OSM может содержать неполные или устаревшие контуры. Ни одного вымышленного здания для заполнения пробелов не добавляется.
- Публичный статический хостинг и трафик имеют лимиты провайдера; бесплатные форматы и библиотеки не означают неограниченный бесплатный трафик.
