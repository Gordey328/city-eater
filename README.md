# CITY EATER

## Потоковый предпросмотр

Параметр `?stream=1` включает отдельный экспериментальный режим: обычные векторные тайлы, ближайшие здания по мере движения, поглощение частей контуров по сетке 2 м и цели по съеденной площади. Арена остаётся 10 × 10 км; радиус ограничен 500 м, площадь и очки растут дальше. Старые прохождения продолжаются по прежним правилам, данные не удаляются. Обычная ссылка пока сохраняет прежний режим.

**Проверка живого источника ещё не завершена:** в доступной тестовой среде OpenFreeMap заблокирован. Геометрия, сохранения и ограниченная загрузка проверены на тестовых ответах и реальных локальных OSM-контурах, но скорость настоящего первого входа, CORS и телефонный FPS не заявляются. При недоступном источнике район не становится пустым или «пройденным». Подробности: [архитектура и ограничения](design/STREAMED_MASK_PREVIEW.md), [контракт тайлов](design/TILE_STREAMING.md).

Одиночная HTML5-аркада: управляй чёрной дырой, поглощай настоящие здания и вырастай. Два вручную выбранных участка OpenStreetMap: **Пушкин** и **Гатчина**, по **10 000 × 10 000 м** каждый. Цель — **80% суммарной площади зданий**, без ограничения времени.

## Карта — главный экран

Игра открывается на обзорной карте: двигай и приближай её, найди город, затем нажми на квадрат **10 × 10 км**. Квадраты не меняют положения при перемещении камеры. Готовые Пушкин и Гатчина доступны через небольшие кнопки; сохранённые районы и прежние городские кампании — через кнопку «Мои районы». Во время подготовки карта остаётся видимой; отмена возвращает к прежнему масштабу. После входа новое касание управляет дырой. Кнопка «К карте» сохраняет прохождение и возвращает к выбору.

Новые свободные квадраты используют детерминированную мировую сетку с постоянными ID. В каждой широтной строке полные ячейки замыкаются по долготе без наложения на линии перемены дат. Размер составляет ровно 10 000 × 10 000 м в выбранной локальной equirectangular-системе; геодезическая ширина может отличаться до 0,15% около полярного предела. Старые городские сетки и сохранения используются без перестроения.

## Любой город: экспериментальная кампания

Дополнительный экран «Границы города и координаты» открывает настоящую обзорную карту Natural Earth, локальный поиск по 34 156 городам GeoNames и ввод координат. Небольшие места, отсутствующие в справочнике, можно выбрать на карте. При недоступном WebGL только обзор выбора имеет честный 2D-вариант на тех же данных; сама игра всегда использует MapLibre/WebGL.

Границы можно получить из OSM или задать вручную. Граница кампании — явно подписанный **прямоугольник административного контура**, не точный полигон города. Он разбивается на регулярные метрические секторы 10 × 10 км в единой локальной проекции города: область 20 × 20 км содержит ровно четыре сектора. Ближайший к выбранному центру идёт первым. Крайние ячейки включают окрестности. Прохождение сохраняется по каждому сектору, а общий прогресс показывается как число пройденных секторов. Площадь ещё не загруженных зданий неизвестна и не выдаётся за общий знаменатель города.

Браузер запрашивает только здания выбранного сектора через единственный намеренно выбранный публичный Overpass VK Maps, разбирает JSON и подготавливает его в Web Worker, затем сохраняет чанки в IndexedDB. Новая быстрая загрузка не включает дорожную/водную/парковую подложку; это подписано при входе. Готовые карты и уже сохранённые полные карты сохраняют свой фон. Готовые карты продолжают использовать self-hosted PMTiles; фон старых полных импортов — локальный GeoJSON; у новых экономных импортов этот слой пуст. Никакого API геокодинга или запросов ко всему миру на каждую букву поиска нет.

Ограничения импорта: один запрос одновременно, пауза 30 с между запросами, сетевой тайм-аут 110 с, ответ не более 40 МиБ, до 100 000 OSM-элементов и 30 000 зданий, подготовка не более 45 с. Отмена прерывает fetch/worker и не запускает отменённый сектор. Нет автоматической смены провайдера или повторных запросов в обход лимита. Плотный центр может быть недоступен; можно выбрать другой сектор. Список участков имеет страницы по девять кнопок, поэтому любой дальний сектор доступен без прохождения первых. Успешный пустой сектор отмечается пустым, а ошибка источника никогда не считается пустотой.

Все игровые здания по-прежнему целиком внутри своего 10км сектора: пересекающие шов контуры исключены, что явно указано в интерфейсе. «Пройден весь город» означает завершение игровых секторов выбранного покрытия, а не обещание поглотить буквально каждый административный объект. При входе с карты стартовый радиус при необходимости подбирается под настоящие здания и показывается игроку. Сохранённый радиус и позиция всегда восстанавливаются.

## Оптимизация поглощения

Слой зданий обновляется добавлением/удалением устойчивых ID, вместо пересоздания всех контуров при каждом поглощении. Эффекты ограничены по числу и вершинам, проекции анимаций кэшируются, пространственные запросы переиспользуют массивы. Награды независимы от косметических эффектов. Запись растущего списка съеденных ID объединяется в контрольные точки; пауза/выход/смена уровня немедленно сохраняют состояние. Детальный воспроизводимый CPU benchmark: [design/PERFORMANCE.md](design/PERFORMANCE.md). Это измерения вычислений, не заявление о FPS телефона.

**Стек:** JavaScript ES modules, Vite, MapLibre GL JS, self-hosted PMTiles, отдельные чанки геометрии, IndexedDB. Нет Mapbox, коммерческих ключей, собственного игрового backend или запросов к публичным OSM tile servers во время игры. Только создание нового сектора обращается к выбранному публичному Overpass; доступность сервиса не гарантируется. Шрифты поставляются с приложением.

## Запуск

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Node.js 22+ рекомендован. Vite выводит `dist/`; относительный `base: './'` подходит для GitHub Pages в подпапке репозитория. Публикация: содержимое `dist/` в `docs/`, файл `docs/.nojekyll`, Pages → branch `main`, directory `/docs`.

Браузеру необходим доступный **WebGL 2**. Если графика отключена или недоступна, игра показывает явное сообщение; обязательный MapLibre не подменяется фиктивной картой.

HTTP-сервер должен поддерживать **Range-запросы** для PMTiles и выдавать `206 Partial Content`. Кросс-доменные карты дополнительно требуют корректного CORS. `file://` не поддерживается.

## Управление

- ПК: WASD / стрелки. Escape — пауза.
- Телефон или мышь: нажми на свободную область карты и тяни плавающий джойстик.
- Светлые здания подходят по радиусу; поглощение начинается автоматически, когда весь контур помещается в отверстие.
- По обновлённому правилу от 09.10.2026 дыра свободно проходит через любые здания. Поглощаются только полностью помещающиеся контуры; движение ограничивает только край арены.
- Прогресс сохраняется автоматически в текущем браузере. Очистка данных сайта удалит прохождения и рекорды.

## Архитектура

- `src/geometry.js`: локальные метрические координаты, минимальный охватывающий круг, Polygon/MultiPolygon с отверстиями, геометрические утилиты, пространственная сетка. Сохранённые старые collision-утилиты не участвуют в текущей игровой механике.
- `src/repository.js`: потоковая подгрузка/выгрузка чанков 1×1 км и индекс активных зданий; уничтоженные ID живут отдельно. Игрок не заходит в ещё не загруженную ещё не загруженную зону игровой геометрии.
- `src/renderer.js`: собственный MapLibre-стиль PMTiles, управляемый GeoJSON-слой зданий, canvas-дыра и ограниченные анимации поглощения.
- `src/state.js`: однократная награда, прогресс по площади, радиус `sqrt(18² + 0.06 × mass)`, результаты и рекорды.
- `src/storage.js`: IndexedDB-прохождения, рекорды и разблокировки; localStorage только для небольших настроек. Версия OSM-набора проверяется перед восстановлением.
- `src/input.js`: клавиатура, pointer capture, плавающий джойстик, pointer cancellation.
- `src/main.js`: жизненный цикл, интерфейс, pause/resume, победа/следующий уровень, сохранения.

На телефоне HUD по умолчанию занимает одну полосу высотой 46 CSS px: прогресс, радиус, сворачиваемые дополнительные показатели и отдельная 44px кнопка паузы.

Камера следует за дырой и непрерывно отдаляется с ростом, сохраняя диаметр дыры около 21% короткой стороны окна. Формула учитывает 512px мировую шкалу MapLibre; удвоение радиуса уменьшает zoom на один уровень. Потоковая геометрия покрывает прямоугольный видимый участок и запас по направлению движения. На старте загружаются 4 чанка, а не вся геометрия 100 км². При цели 80% радиус составляет приблизительно 480 м в Пушкине и 425 м в Гатчине; активная область остаётся локальной.

## Данные и лицензии

Игровая база содержит **25 202 реальных здания**: 12 721 в Пушкине, 12 481 в Гатчине. Каждое целиком внутри локального квадратного участка. Идентификаторы `w<OSM way ID>` / `r<OSM relation ID>` стабильны внутри версии набора. Дубликаты и составные объекты нормализованы, внутренние дворы сохранены.

Данные © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Производная база, исходные разрешённые выгрузки, запросы, timestamps и SHA-256 опубликованы в [`public/data`](public/data/README.md). Сырые исходники доступны для лицензии и воспроизводимости, но игра их не загружает. Пайплайн и проверка доставки находятся в `scripts/`.

Исходный код приложения: MIT, см. `LICENSE`. MapLibre GL JS 6.13+: BSD-3-Clause; PMTiles: BSD-3-Clause. Manrope и Unbounded: SIL Open Font License; см. `THIRD_PARTY_NOTICES.md`.

## Проверка

`npm test` проверяет геометрию, импорт и кампании: геометрию, свободное движение внутри арены, монотонный zoom на радиусах 13–500 м, реальные границы и ID всех зданий, площадь прогресса, однократную награду, смену версии, IndexedDB, чанки/повторную загрузку/ошибки и ограниченный размер активной сцены к концу уровня.

В URL `?test=1` включается диагностическая панель. Она позволяет переместиться к настоящему подходящему зданию, выгрузить и вернуть чанки, сохранить контрольную точку и ускоренно достичь цели на настоящих OSM-ID. Дополнительный `?test=1&hud=1` открывает явно обозначенный неподвижный предпросмотр HUD с контрольными значениями, без карты, игрового цикла, наград или сохранений.

Панель изменяет прогресс **только текущего браузера**; по обычному адресу она отсутствует. FPS диагностируется по реальному uncapped времени кадров; физический timestep ограничен отдельно.

### Известные ограничения прототипа

- Реальные iPhone/Safari и Android/Chrome ещё требуют отдельного тестирования FPS, памяти и длительных сессий. Размер окна настольного браузера не заменяет реальные мобильные устройства.
- Геометрия использует локальную equirectangular-проекцию. Все новые секторы одной кампании используют общую широту проекции, поэтому края сетки совпадают. Это точный квадрат в выбранной локальной системе, не геодезическая съёмка. Версия сетки и её метрическая основа входят в ID; ранее сохранённые кампании остаются доступны со своей исходной сеткой.
- Баланс роста и длительность прохождения требуют пользовательских тестов. Автоподбор районов и автоматическая оценка сложности не реализованы согласно GDD.
- OSM может содержать неполные или устаревшие контуры. Ни одного вымышленного здания для заполнения пробелов не добавляется.
- Публичный статический хостинг и трафик имеют лимиты провайдера; бесплатные форматы и библиотеки не означают неограниченный бесплатный трафик.

## Валидация импорта

Разовый живой запрос сектора Луги: HTTP 200 + CORS, 8,45 МБ за 26,8 с, 6 510 зданий, 67 чанков, 1 809 335,419 м². Контрольные тесты подтвердили реальные ID, площади, границы, загрузку четырёх начальных чанков, повторное открытие локального кэша и отсутствие восстановленных поглощённых зданий. Эти показатели относятся к конкретному запросу и тестовой среде, не гарантируют срок или полноту другого города.

Дополнительно: [архитектура и условия источников](design/ANY_CITY_ARCHITECTURE.md), [сведения о мировом поиске](public/data/world/provenance.json). `npm audit` проверен после обновления MapLibre и XML-зависимости; известных проблем в установленном дереве на момент сборки не найдено.

## Загрузка меньшего объёма

Новый сетевой запрос загружает только здания одного полного 10км квадрата. На сохранённом примере Луги одинаково сериализованный ответ стал на 47,22% меньше, а все 6510 игровых контуров и суммарная площадь сохранились. Это сравнение данных, не обещание сетевой задержки. Игровое управление и цель 80% включаются только после получения полного индекса зданий; затем подробные местные чанки подгружаются по мере движения. Панорамирование карты не запускает запросы OSM. Обновление фоновых улиц отдельным запросом пока не предлагается, чтобы не нарушать версии сохранений. Подробнее: [design/LEAN_SECTOR_LOADING.md](design/LEAN_SECTOR_LOADING.md).
